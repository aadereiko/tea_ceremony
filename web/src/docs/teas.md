# Teas and the catalog

> **In short:** the **Tea catalog** is one shared list of teas, used by every room. Add a tea
> once, and any room can pick it.

## Add a tea

- **Inside a room** (host): press **Add tea**, then pick one from the catalog or describe a new one.
  A new tea is added to the catalog and the room at the same time.
- **From the catalog**: open **Catalog** in the bar at the top and press **+ New tea**.

## What a tea has

| Field | What to put there |
|---|---|
| **Name** | The tea's name, like "Dong Ding oolong". Each name exists once in the catalog. |
| **Icon** | A picture for the tea. Picked at random if you skip it. |
| **Colour of the brew** | The colour of the tea in the cup. Hover a colour to see which teas brew like it. |
| **Ingredients** | What's in it. Pick from the list or type new ones. See [Ingredients](/docs/ingredients). |
| **Notes** | Brewing steps, like "80 °C for 3 minutes". |
| **Where to buy** | The [tea shops](/docs/shops) that sell it. |

> **Careful:** notes are shown even while a tea is a mystery. Don't write its name there.

## Edit or delete a tea

- Editing a tea changes it **in every room** that has it.
- A tea can only be deleted from the catalog once no room is tasting it.

## Scores belong to the room

The same tea tasted in two rooms keeps **two separate sets of scores**. The catalog only stores
what the tea is, not what people thought of it.
